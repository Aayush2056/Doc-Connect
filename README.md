# 🏥 Doc-Connect

Doc-Connect is a full-stack doctor appointment booking platform built using the **MERN Stack**. It allows patients to find doctors, view doctor details, book appointments, make online payments, and manage their appointments.

Doctors can register, manage their appointments, and update appointment statuses. An admin dashboard is also included to manage registered users and doctors.

---

## 🚀 Features

### 👤 Patient

- User registration and login
- JWT-based authentication
- Browse all available doctors
- Search doctors by specialization
- View doctor details
- View doctor fees, experience and availability
- Book doctor appointments
- View personal appointments
- Cancel unpaid appointments
- Online payment using Razorpay
- Track appointment and payment status
- Logout functionality

### 👨‍⚕️ Doctor

- Doctor registration
- Doctor login
- Profile information
- Upload doctor profile image
- Set availability
- View assigned appointments
- View patient details
- Update appointment status
- Separate doctor dashboard and navigation

### 🛠️ Admin

- Admin authentication
- View all registered users
- Delete users
- View all registered doctors
- Delete doctors
- Separate admin dashboard
